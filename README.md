# Module01 Environment 

 

## 1. Название и цель 

 

Module01 Environment — учебный проект по организации цифровых материалов. 

 

Цель проекта — показать правильную структуру файлов, безопасную работу с учебными данными и ведение истории изменений. 

 

## 2. Состав файлов 

 

Проект состоит из следующих элементов: 

 

- notebooks — учебные notebook-файлы; 

- data — учебные данные; 

- docs — документация проекта. 

 

## 3. Как открыть 

 

Для работы с проектом необходимо открыть репозиторий GitHub. 

 

Учебный notebook находится в папке notebooks. 

 

Учебные данные находятся в папке data. 

 

Документация находится в папке docs. 

 

## 4. Проверка 

 

Для проверки проекта необходимо убедиться, что все основные папки присутствуют, файлы открываются, а README содержит описание проекта. 

 

## 5. Ограничения 

 

В репозитории не используются персональные данные, пароли, токены доступа и другая конфиденциальная информация. 

 

В проекте используются только безопасные учебные данные. 

 

## 6. История версий 

 

История изменений проекта записывается в файле version_log.md. 

 

В истории фиксируются основные изменения структуры и содержимого проекта.
